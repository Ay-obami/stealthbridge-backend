# Contributing to StealthBridge Backend

This project is public testnet research. Open a design PR before any code that moves funds. Keep untrusted provider payloads strictly validated, never log proof witnesses or real identity documents, and write transition tests for all exceptional paths. Include a threat-model change whenever adding a new on-chain or off-chain data disclosure. No funding requests or Drips issues are open yet; milestones will be defined after the feasibility baseline.
