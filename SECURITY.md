# Security Policy — StealthBridge (backend)

## Scope
This repository is an experimental **Stellar Testnet-only** research project, not audited financial software. Real funds, production KYC data, private payment witnesses, wallet recovery phrases, relayer credentials and actual fiat processing must not be used.

## Responsible reporting
Do not disclose critical issues in public GitHub issues. If the repository's GitHub private vulnerability reporting is enabled, use the private **Security → Report a vulnerability** flow. Otherwise, contact the organization maintainers privately to coordinate a confidential report; the permanent security contact is a governance task.

Include impacted source, safe reproduction steps and expected security property, but no live secrets or third-party personal data.

## Important
No guarantee of confidentiality or reliable payment execution is made until the relevant contracts, proofs, integrations and security review are completed.
